## 1. Computer Networking Fundamentals
Learn IP addresses, TCP/IP, DNS, DHCP, routers, switches, LAN and WAN networks.

## 2. Network Traffic Analysis
Understand network communication and identify suspicious activities using tools like Wireshark.

## 3. Firewall Configuration
Learn firewall rules, access control, traffic filtering and network protection techniques.

## 4. Understanding Network Attacks
Study common cyber threats:
- Man-in-the-Middle attacks
- Denial-of-Service attacks
- DNS spoofing
- Packet sniffing
- Brute-force attacks

## 5. Linux Operating System Skills
Practise Linux commands, file permissions, user management and basic shell scripting.

## 6. Vulnerability Assessment
Learn how to identify security weaknesses using tools such as Nmap and OpenVAS in authorized environments.

## 7. Intrusion Detection and Prevention
Understand IDS and IPS technologies to detect suspicious network activities.

## 8. Network Security Protocols
Learn HTTPS, SSL/TLS, SSH, IPsec and VPN technologies.

## 9. Incident Response Skills
Develop skills in identifying threats, collecting evidence, investigating incidents and documenting security events.

## 10. Practical Cybersecurity Experience
Build a virtual lab and practise network scanning, traffic analysis, firewall configuration and authorized security testing.
